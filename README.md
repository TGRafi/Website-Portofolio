# Website-Portofolio
"Website Portofolio"

Sebuah portofolio responsive yang dibangun menggunakan HTML, CSS, dan JavaScript murni, serta memanfaatkan Bootstrap 5 untuk tata letak yang cepat dan mobile-friendly.

Proyek ini didesain untuk menampilkan informasi diri, riwayat pendidikan, keahlian, dan daftar proyek. Fitur utamanya adalah navigasi gulir halus (smooth scroll) dan penyorot menu aktif (scroll spy) yang dibuat secara kustom menggunakan JavaScript, menciptakan pengalaman pengguna yang mulus dan interaktif.
